Verification Bench

Point it at a world spec and a folder. It lists every file for you to open, look at and mark — and for any file the spec knows about, it traces what that document is carrying: the registered values, the traps, the tasks that consume it, the reference anchor behind it, and the sibling documents it has to agree with. Nothing is uploaded; both stay on this machine.

1

Locate the World Spec

The .xlsx workbook with the ① World & Scenario, ② Canonical Values, ③ Tasks and ④ Artifacts tabs. It is read here in the browser and never sent anywhere. Tracing needs it; the checklist works without it.

2

Locate the reference anchors

The folder of external reference documents the spec points at — the standards and published reports behind the world. Optional: without it the trace still names the reference, but cannot open it or tell you one is missing.

3

Choose the file system folder

Pick the top of the tree. Sub-folders are walked and become the section headings. Dot-files are skipped.
